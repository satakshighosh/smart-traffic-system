# smart-traffic-system
Physically Informed LSTM-Powered Traffic Congestion Detection and Forecasting Model with Dynamic Signal Timing using Python, OpenCV and YOLOv8 and Simulated on SUMO

# About

This project simulates a dynamic traffic signal timing system using a physically informed LSTM model to forecast vehicular congestion, SUMO traffic simulation, along with graphical visualisation of performance.

## Requirements
- Python 3.10+
- SUMO 1.18+
- pip

## Setup
```bash
git clone https://github.com/satakshi-ghosh/smart-traffic-system.git
cd smart-traffic-system
python -m venv venv
